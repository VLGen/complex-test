# 🧠 RAG-ассистент менеджера O-complex

Прототип ассистента для обработки обращений клиентов: на вход подаётся сообщение клиента,
на выходе система выдаёт **два блока** — вежливый ответ клиенту и подсказку менеджеру
по допродажам на основе базы знаний.

Проект выполнен как тестовое задание и демонстрирует работу с локальными LLM,
RAG-пайплайном и векторным хранилищем.

---

## 🎯 Что решает

Менеджер в диалоге с клиентом получает:

- **Готовый ответ клиенту** — вежливый, краткий, опирающийся только на базу знаний.
- **Подсказку по допродажам** — конкретную рекомендацию, которую клиент не видит.

Оба блока генерируются на основе одного и того же retrieved-контекста, но с разными
промптами и разными акцентами. Это ключевая идея: RAG-ядро одно, а выводов из него — два.

## 🏗 Архитектура

Обращение клиента (Gradio)
│
▼
┌─────────────────────────────┐
│ Retriever (LlamaIndex) │
│ multilingual-e5-large │
└─────────────────────────────┘
│
▼
┌─────────────────────────────┐
│ ChromaDB (persistent) │
│ top-k релевантных записей │
└─────────────────────────────┘
│
▼
┌──────────────┬──────────────┐
│ Промпт 1 │ Промпт 2 │
│ → клиенту │ → менеджеру │
└──────────────┴──────────────┘
│ │
▼ ▼
Ответ клиенту Подсказка менеджеру


Система разделена на **ядро** (`indexer.py`, `rag.py`, `prompts.py`) и **интерфейс**
(`app.py`). Ядро не знает, откуда пришёл запрос — из Gradio или из API. Это позволяет
в дальнейшем подключить AmoCRM через тонкий адаптер без переписывания логики.

---

## 🧰 Технологический стек

| Слой | Инструмент | Обоснование |
|---|---|---|
| RAG-фреймворк | **LlamaIndex** | Быстрый прототипинг RAG, встроенные ретриверы |
| Векторная БД | **ChromaDB (persistent)** | Локально, без облака, данные переживают перезапуск |
| Embeddings | **intfloat/multilingual-e5-large** | Open-source, хорошо работает с русским |
| LLM | **Ollama** (qwen2.5:7b) | Полностью локальный инференс, без API-ключей |
| Web-UI | **Gradio** | Минимум кода, диалоговый интерфейс из коробки |
| Конфигурация | **pydantic-settings + .env** | Типизация, валидация, отделение секретов от кода |

## 🚀 Запуск

### 1. Предварительные требования

- Python 3.10+
- [Ollama](https://ollama.com/) установлена и запущена
- Скачанная модель, например:
  ```bash
  ollama pull qwen2.5:7b

### 2. Установка
git clone <repo-url>
cd rag-amo-assistant
python -m venv .venv
source .venv/bin/activate       # Linux / macOS
.venv\Scripts\activate          # Windows
pip install -r requirements.txt

### 3. Конфигурация
Скопируйте .env.example в .env и при необходимости отредактируйте:
cp .env.example .env

### 4. Сборка индекса (один раз)
python -m scripts.build_index

### 5. Запуск интерфейса
python -m src.app

Откройте http://127.0.0.1:7860 — увидите диалоговое окно слева и панель
менеджера справа.
